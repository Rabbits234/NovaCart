# NovaCart

NovaCart is a smart e-commerce web application that I’m currently building as a full-stack project.

The idea is to create a simple and modern shopping platform with a wide range of products, secure authentication, and a smooth user experience.

## Status

This project is currently **in progress**. Some of the core backend and authentication features are working, while other parts of the application are still being developed.

## Tech Stack

* React + TypeScript + Vite
* Tailwind CSS
* FastAPI
* SQLAlchemy
* PostgreSQL
* JWT Authentication

More features and improvements will be added as I continue working on it.
